# REPORTING TOOL

Create a bounded report (year, quarter, or month) that contains the following information:

* Total number of calls for the period, broken down into EMS (any NERIS type that is prefixed with `MEDICAL_` or public lift assists) and fire (all other call types). Include percentages.
* Average number of responding personnel per call
* Average times (calculate all times and drop the top and bottom 10%, as well as any calls with zero times) including:
  - Dispatch to en route
  - Dispatch to arrival
  - Average time on scene
* Total number of calls that are concurrent (overlap) with percentages
* Total number of calls where mutual or automatic aid was given and received (seperate numbers) with percentages
* Total number of EMS mutual aid calls (calls for medical call types where aid was given), both totals and separated out by district
* Total number of calls per shift (Duty Night, Day Shift) with percentages
* Total number of calls with (including percentage):
  - Hazardous materials calls
  - Motor vehicle accidents
  - Carbon Monoxide emergencies (including those where nothing was found)
* Total number of calls that (including percentage):
  - Drone Team Calls: The unit UAV163 responded to
  - Rehab Team Calls: The unit S263 responded to
